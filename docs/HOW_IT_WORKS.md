# How MergePact works

1. **Fund the issue** — A maintainer locks Testnet MON and publishes one acceptance sentence on Monad Testnet.
2. **Claim the work** — A contributor sees the funded pact and claims it on-chain.
3. **Record the proof** — After work on GitHub, the contributor submits a public proof URL.
4. **Release the bounty** — The maintainer reviews on GitHub and releases the locked Testnet MON.

GitHub remains where code is reviewed. Monad Testnet holds funding, assignment, proof, and release state.

See [PRD.md](./PRD.md) for full specification.
