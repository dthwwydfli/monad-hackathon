# How commit works

1. **Fund the issue** — A maintainer locks Testnet MON on a GitHub issue and writes one sentence for what done looks like.
2. **Claim the work** — A contributor sees the funded issue and claims it.
3. **Post the proof** — After shipping on GitHub, the contributor pastes a public PR or commit URL.
4. **Release the bounty** — The maintainer reviews on GitHub and sends the locked Testnet MON.

GitHub is where you review the code. Monad Testnet shows who funded what, who claimed it, and whether it was paid.

The on-chain contract is still named `MergePact.sol` — commit is the product name for the app.

See [PRD.md](./PRD.md) for full specification.
